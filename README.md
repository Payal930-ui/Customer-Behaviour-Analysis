# Customer Shopping Behavior Analysis

## 1. Project Overview

This project analyzes customer shopping behavior using transactional data from **3,900 purchases** across various product categories. The goal is to uncover insights into spending patterns, customer segments, product preferences, and subscription behavior to guide strategic business decisions.

The end-to-end workflow covers data cleaning and EDA in Python, structured business-question analysis using SQL, and an interactive Power BI dashboard for visual storytelling.

**Tech Stack:** Python (Google Colab), Pandas, SQLite3, SQL, Power BI

---

## 2. Architecture Flow

https://github.com/Payal930-ui/Customer-Behaviour-Analysis/blob/main/architecture%20of%20customer%20%20behaviour.png

The pipeline flows as follows:

1. **Download CSV Dataset** — raw `customer_shopping_data.csv` (3,900 rows, 18 columns)
2. **Data Cleaning & Preprocessing** — Python in Google Colab (missing value imputation, snake_case standardization, feature engineering, redundant column removal)
3. **Load Cleaned Data into SQLite3** — cleaned DataFrame written into a local `customer_shopping.db`
4. **Data Analysis using SQL (SQLite3)** — 10 business-question queries run directly in the notebook
5. **Export Query Results / Cleaned Data to CSV** — `cleaned_data_export.csv`
6. **Upload CSV to Power BI** — imported into Power BI Desktop
7. **Dashboard & Presentation** — interactive Power BI dashboard, followed by a PPT summarizing key findings and business recommendations

## 3. Dataset Summary

- **Rows:** 3,900
- **Columns:** 18
- **Key Features:**
  - Customer demographics — Age, Gender, Location, Subscription Status
  - Purchase details — Item Purchased, Category, Purchase Amount, Season, Size, Color
  - Shopping behavior — Discount Applied, Promo Code Used, Previous Purchases, Frequency of Purchases, Review Rating, Shipping Type
- **Missing Data:** 37 values in the `Review Rating` column

---

## 4. Exploratory Data Analysis (Python — Google Colab)

Data preparation and cleaning were done in **Google Colab** using Python.

- **Data Loading:** Imported the dataset using `pandas`.
- **Initial Exploration:** Used `df.info()` to check structure and `.describe()` for summary statistics.
- **Missing Data Handling:** Checked for null values and imputed missing values in `Review Rating` using the median rating of each product category.
- **Column Standardization:** Renamed columns to `snake_case` for readability and consistency.
- **Feature Engineering:**
  - Created an `age_group` column by binning customer ages.
  - Created a `purchase_frequency_days` column derived from purchase data.
- **Data Consistency Check:** Verified that `discount_applied` and `promo_code_used` were redundant; dropped `promo_code_used`.
- **Database Integration:** Loaded the cleaned DataFrame into a local **SQLite3** database (via Python's built-in `sqlite3` library) directly inside Colab, so all SQL analysis could run without needing an external database server.

---

## 5. Data Analysis using SQL (SQLite3, run inside Google Colab)

Using `sqlite3` + `pandas.read_sql_query()`, the cleaned data was queried to answer key business questions:

1. **Revenue by Gender** — Compared total revenue generated by male vs. female customers.
2. **High-Spending Discount Users** — Identified customers who used discounts but still spent above the average purchase amount.
3. **Top 5 Products by Rating** — Found products with the highest average review ratings.
4. **Shipping Type Comparison** — Compared average purchase amounts between Standard and Express shipping.
5. **Subscribers vs. Non-Subscribers** — Compared average spend and total revenue across subscription status.
6. **Discount-Dependent Products** — Identified the 5 products with the highest percentage of discounted purchases.
7. **Customer Segmentation** — Classified customers into New, Returning, and Loyal segments based on purchase history.
8. **Top 3 Products per Category** — Listed the most-purchased products within each category.
9. **Repeat Buyers & Subscriptions** — Checked whether customers with more than 5 purchases are more likely to subscribe.
10. **Revenue by Age Group** — Calculated the total revenue contribution of each age group.

> All queries were written and executed as standard SQL strings passed to SQLite3 within the Colab notebook — no external database setup required, making the project fully self-contained and reproducible in a single notebook environment.

## 6. Dashboard & Presentation (Power BI)

The final cleaned dataset (exported from the Colab/SQLite3 pipeline) was loaded into **Power BI** to build:

- An **interactive Customer Behavior Dashboard** featuring:
  - Number of Customers, Average Purchase Amount, Average Review Rating (KPI cards)
  - % of Customers by Subscription Status
  - Revenue by Category & Sales by Category
  - Revenue by Age Group & Sales by Age Group
  - Filters/slicers for Subscription Status, Gender, Category, and Shipping Type
- A **presentation deck** summarizing key findings and business recommendations for stakeholders.

## 8. How to Run

1. Open the notebook in Google Colab.
2. Upload the dataset (`customer_shopping_data.csv`).
3. Run all cells — this cleans the data, engineers features, and loads it into an in-notebook SQLite3 database.
4. Run the SQL query cells to reproduce each business-question analysis.
5. Export the cleaned CSV and open `customer_behavior_dashboard.pbix` in Power BI to explore the dashboard.
